# 첫 3D 플레이 버전

## 플레이 흐름

느티나무 광장 → 근접 상호작용 → 벤치 / 마을 게시판 / 카페, 오후 / 바람의 정원. 공간 전환 시 해당 공간의 스폰으로 이동하며, 카페와 정원에는 광장 복귀 상호작용이 있습니다. 처음부터 캐릭터를 조작할 수 있고 로그인은 없습니다.

React는 HUD·대화상자·방문 기록을 관리합니다. R3F의 프레임 루프는 캐릭터 좌표·걷기/대기/앉기·카메라 추적을 처리합니다. 좌표 스냅샷은 약 10Hz로 UI에 전달하여 매 프레임 React 전체 렌더를 피합니다. 미니맵과 근접 버튼은 같은 스냅샷을 사용합니다.

## 입력과 충돌

PC와 가상 조이스틱 입력을 카메라 기준 월드 방향으로 합산·정규화합니다. 포커스 상실·탭 전환·대화상자 표시 시 입력을 지워 계속 움직이는 현상을 막습니다. 프레임 delta를 제한하고 이동을 작은 구간으로 나눈 후 x/z를 별도로 판정하여 벽을 따라 미끄러지고 장애물을 통과하지 않게 합니다.

`lib/world.ts`가 충돌과 근접 대상의 기준입니다. 새 오브젝트를 추가할 때 시각 메시와 충돌 데이터를 함께 바꿔야 합니다. 앉기는 지정된 좌석으로 이동하고, 일어나면 충돌 없는 앞자리로 이동합니다. 카메라는 고각의 3인칭 추적이며 드래그 회전과 휠 줌을 제공합니다.

## 렌더링과 모바일

그림자는 1024px 한 개 광원으로 공간에 들어갈 때 계산하고, 움직이는 캐릭터에는 접지 그림자를 사용합니다. DPR은 최대 1.5로 제한했습니다. 바닥 타일·잔디·꽃은 인스턴싱하여 드로콜을 줄였습니다. 외부 모델·이미지·웹폰트 로딩 없이 실행할 수 있습니다. 모바일에서는 미니맵·보조 패널을 줄이고 조이스틱과 상호작용 버튼을 노출합니다. safe-area를 반영합니다.

## 데이터와 접근성

별명과 작성 메모는 로컬 저장소를 사용하며 저장 오류를 처리합니다. 공개 서버 게시판·인증·유저 추적은 없습니다. 버튼에 이름을 제공하고 대화상자에서는 이동을 멈춥니다. 3D 게임 자체에는 WebGL과 시각 조작이 필요하며 완전한 비시각 게임 플레이는 지원하지 않습니다.

## 후속 단계

1. 권한이 있는 게임 서버와 이동·상호작용 검증, 실시간 위치 동기화
2. 계정/가명 관리, 공유 게시판 API, 신고·차단
3. 사용자 공간 저장과 에셋 배치/충돌 규칙
4. AI 호스트 및 음성·영상 동의/권한 흐름

이번 버전은 이후 네트워크 계층을 붙일 수 있도록 렌더링과 월드 규칙을 분리하지만 멀티플레이를 구현했다고 표시하지 않습니다.
